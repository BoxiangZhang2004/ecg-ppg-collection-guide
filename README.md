# ECG × PPG 采集向导

公开网页：https://boxiangzhang2004.github.io/ecg-ppg-collection-guide/

依据《ECG与PPG血压预测采集流程_最终版.pdf》（2026.11.12）制作的静态采集现场引导工具。

## 使用

1. 填写受试者编号并完成准备核对，开始开录前 3 分 30 秒坐姿放松。
2. 放松结束后，在采集软件开始保存 ECG、PPG，再同步点击网页“已开始保存 ECG / PPG，启动 00:00”。
3. 跟随当前阶段提示。默认记录 18 分钟：3 轮 40 秒坐姿踏步、90 步/分钟；4 次血压及额温测量。
4. 每次测压前，在采集软件查看波形，人工核验连续 80 秒有效 ECG、PPG。掉线或明显伪差时，标记信号不稳；恢复稳定后重新计 80 秒。
5. 实际按下血压计后点击按钮并确认；额温在实际按键后 10 秒提示，输入读数后再次核对。血压结束并完全放气时另行确认。
6. 静坐阶段可增加 10 / 30 / 60 秒、自定义延时，或保持当前阶段等待操作。采集时钟连续向前，后续安排顺延。运动段固定 40 秒。
7. 末次完全放气后至少 30 秒、受试者恢复后，在采集软件停止保存，再点击网页结束确认。核对文件、设备结果及备份，导出 CSV 和完整 JSON。

网页不连接采集板、血压计或额温枪，不自动判断波形质量，也不预测血压。按键确认只表示测量已启动；血压结果以设备保存、导出的结果为准。有效段、放气及恢复情况均由操作者判断。

两次测压按上次完全放气至下次按键至少 240 秒控制。设备说明书更严格时，在准备页设置更长的最小间隔。测压超过 60 秒、缺少人工确认、信号不足时，后续阶段自动等待并顺延。充放气及放气后至少 30 秒仍需在原始波形中标记为干扰区间。

## 保存与浏览器

- 受试者编号、额温、事件记录仅使用当前浏览器 `localStorage` 保存，无后端、无统计 SDK，无数据上传接口。
- 导出内容包含实际采集秒数、电脑 ISO 时间、各次操作、温度、阶段、延时原因及结束核对。CSV 包含 UTF-8 BOM 并防护公式注入。
- 浏览器刷新后保留实际时间和阶段，运行中恢复时需要操作者核对后继续。页面离开前台或定时器中断超过 5 秒时也会等待核对，避免自动跳过多个阶段。踏步提示在 40 秒时停止。
- 保持页面在前台，避免锁屏。尝试使用屏幕唤醒锁，但系统及浏览器可能不支持。提示音需要首次用户点击解锁；语音依赖浏览器的中文语音能力。
- 正常在线打开并完成缓存后，可离线使用已缓存的页面。离线缓存不替代导出备份；浏览器清理网站数据会删除本机记录。
- 新受试者会清空当前记录，操作前请先导出。请只使用一个标签页进行一次采集。

## 本地启动及验证

无构建步骤，无第三方运行时依赖。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
node --test tests/engine.test.mjs
```

默认时间线：按键 01:30、06:30、11:30、16:30；踏步 04:00、09:00、14:00；结束 18:00。开录前放松单独计时。

GitHub Pages 从 `main` 分支根目录发布，`.nojekyll` 关闭 Jekyll 处理。
