# ECG / PPG 采集计时

公开网址：https://boxiangzhang2004.github.io/ecg-ppg-collection-guide/

内部采集使用的全屏提示工具。开始时仅填写受试者姓名、编号，之后按屏幕提示确认操作。

- 开录前静坐 3:30；在采集软件开始保存后，点击确认启动 00:00。
- 默认连续记录 18:00。中央只显示当前动作、倒计时和当前确认按钮，下方为加时栏。
- 运动阶段整屏显示左右交替节拍器：90 步/分钟，每次 40 秒，共 3 次。运动时间固定，不提供运动加时。
- 测压时直接显示“现在测血压”，实际按下设备后点击确认；10 秒后提示测额温。
- 额温输入后在同一屏幕核对一次，确认后进入下一项。血压测量结束、完全放气时另行确认。
- 测量完成较早时立即显示静坐提示，仍按流程预留测压时间和放气后至少 30 秒缓冲。
- 测压前须人工确认连续 80 秒有效波形。“信号不稳”会重置有效段；信号稳定后重新计满 80 秒。
- 加时支持 5 / 10 / 30 / 60 秒和自定义秒数；后续统一顺延。测压超过 60 秒、确认未完成或间隔不足时等待并顺延。
- 两次测压从上次完全放气至下次按键至少 240 秒。请同时遵守设备说明书；更严格时使用加时保持足够间隔。
- 结束时确认受试者恢复并在采集软件停止保存，然后导出 CSV / JSON，核对原始波形、血压计结果并备份。

依据《ECG与PPG血压预测采集流程_最终版.pdf》（2026.11.12）。默认测压节点 01:30、06:30、11:30、16:30；踏步节点 04:00、09:00、14:00。

网页不连接采集板、血压计或额温枪，不自动判断波形质量。姓名、编号、额温与操作记录仅存当前浏览器，无后端、无统计 SDK、无数据上传接口。按键确认只表示设备测量已启动，血压结果以设备保存记录为准。

保持页面前台，避免锁屏。网页尝试请求全屏及屏幕常亮；系统不支持时仍使用全窗口布局。语音依赖浏览器的中文语音能力，可在“更多”中试听或关闭。

运行中刷新或离开页面超过 5 秒后，需要核对当前状态后继续，不自动跳过操作。首次正常打开并完成缓存后，可离线使用。浏览器清理网站数据会删除本机记录；新受试者开始前请导出当前记录。
